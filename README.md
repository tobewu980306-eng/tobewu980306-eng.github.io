# Chef Tobe Wu - 旬味當代料理主廚個人網站 (附聖誕主廚小虎 AI 客服 🐯👨‍🍳🎄)

本專案為 **Chef Tobe Wu (吳主廚)** 的個人私廚與旬味料理風土誌網站，特別配備了身穿聖誕廚師裝的 **聖誕主廚小虎 AI 助理**，支援透過 **Google Apps Script** 連線至 **OpenRouter (Claude Haiku 5.5)** 解答料理與私廚預約諮詢。

## 🌐 網站正式上線網址
👉 [https://tobewu980306-eng.github.io/](https://tobewu980306-eng.github.io/)

---

## 🌿 網站美編與料理特色
1. **食材風土視覺美學**：
   - 暖焙黑松露岩灰、藏紅花金、初採香草綠大地色系。
   - 典雅襯線字型 (`Noto Serif TC` / `Cinzel`) 與精緻排版。
2. **四大核心區塊**：
   - **主廚哲學**：敬畏自然、尊榮食材，以天然熟成與柴燒炭火淬鍊鮮味。
   - **風土食材庫**：南投野採牛肝菌、宜蘭冰溫熟成野生紅甘、雲林天然低溫發酵黑蒜、花蓮放牧櫻桃鴨。
   - **旬味美饌菜單**：展示精緻季節套餐與食材配搭。
   - **廚藝年誌與私廚預約**：星級名廚經歷與尊榮客製盛宴預約方式。
3. **聖誕主廚小虎 AI 客服 🐯👨‍🍳🎄**：
   - 戴著聖誕主廚帽、手握木匙、圍著紅色圍巾與金色鈴鐺。
   - 專門介紹主廚菜單、風土食材故事、私廚預約諮詢與聖誕暖心甜點。
